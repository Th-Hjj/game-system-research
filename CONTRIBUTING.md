# Contributing

Keep changes focused and core instructions concise. Useful contributions include clearer explanations, evidence-backed cases, tool fixes and reproducible failures.

Include the relevant game/build, environment and evidence. Distinguish static findings, observations and unknowns; keep case-specific procedures outside the generic Skill.

Do not commit game files, extracted assets, decompiler dumps, credentials, personal paths or bundled third-party tools. Share only material you are authorized to distribute.

Run `node scripts/check-package.cjs` and test any changed behavior. Package checks alone do not establish research correctness.
