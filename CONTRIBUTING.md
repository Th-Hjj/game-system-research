# Contributing

Useful contributions include a new evidence-backed case, a clearer explanation, a tool compatibility fix or a reproducible failure.

For a case, include the game/build identity, research question, readable report and a compact evidence index. State which conclusions are static, observed or still open. Keep engine-specific material outside the generic Skill.

For a helper change, describe the environment and failure, include the smallest relevant diagnostic, and verify the changed behavior. Run `node scripts/check-package.cjs` before submitting a pull request.

Do not attach game binaries, extracted assets, full decompiler dumps, credentials, personal paths or third-party tool bundles. Use file hashes, relevant locations and your own analysis to make findings traceable. Only share materials you are authorized to share.

Please keep the core instructions concise. Improvements should clarify the research method rather than turn one case into a mandatory workflow.
