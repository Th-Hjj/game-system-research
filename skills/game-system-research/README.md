# game-system-research v0.1.8

Understand an existing game system through evidence-backed research. The report is written for developers unfamiliar with the game: picture what players do and understand how key rules combine to create choices, constraints and changes in play. A fully developed system explanation forms the main body; its depth follows the research question. Concision removes repetition and digressions, not the reasoning that connects the parts. Technical evidence stays separate.

Copy this folder to your agent's skills directory, open a new session and invoke:

```text
$game-system-research
Game: <title or installation folder>
Question: <what you want to understand>
```

[SKILL.md](SKILL.md) contains the instructions. The [native-analysis reference](references/native-analysis.md) and bundled export helper are optional, not prerequisites for every game.

See the [installation guide](https://github.com/Th-Hjj/game-system-research/blob/main/docs/usage.md). Original project materials are MIT-licensed; game files and third-party tools are not included.
